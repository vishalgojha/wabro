What WaBro Does

Built for approved outreach, not general WhatsApp operations

Linking (pairing code or QR) happens on the setup page. WaBro sends approved batches through the linked number; it does not read chats or run an inbox.

Batches

Approval-bound send batches

A batch goes out only with the recipients and exact message text approved for it. That approval record is stored with the batch.

Execution

Run delivery from the browser

Link WhatsApp once with a pairing code or QR from the browser. Approved batches are then sent by the server through that link.

Tracking

See what is real, hide what is not

Live connection status and batch progress are shown. Numbers the backend cannot track yet are marked "Not available yet" instead of showing fake zeros.
