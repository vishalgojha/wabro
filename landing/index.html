What it does

💬

Pairing-code linking

Link WhatsApp from the browser with a pairing code (or QR). The server sends only through that linked number.

✅

Approval-bound batches

Every batch carries the recipients and exact message text approved for it, recorded with the batch. No approval, no send.

🛡

Opt-out respect

STOP replies are recorded as opt-outs and excluded from future batches. Ambiguous identities are surfaced, never guessed.

📊

An honest dashboard

Live WhatsApp connection status, with anything the backend cannot track yet marked "Not available yet" instead of fake zeros.

How It Works

1

Link WhatsApp

Enter a pairing code (or scan a QR) from the setup page to link WhatsApp. No app installation needed.

2

Approve a batch in chat

Recipients and the exact message text are prepared with Instinct and approved before anything is sent.

3

Watch it send

The batch goes out through the linked number with spaced timing. Results come back in chat; the dashboard shows the live connection status.
